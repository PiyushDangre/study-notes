## OOPS Concepts

- Aggregation - One object contains members of another object type. But this is **weak** association. For eg. Team object has a list of Player objects as its data member. Player can exist without team - hence weak.
HAS-A Relationship

- Composition - One object contains members of another object type. But this is **strong** association. For eg. House object has collection of Room objects. Without house no room hence strong association.
HAS-A Relationship

- Encapsulation - This is the practice of protection of data members by declaring them as private giving them access through the public member functions. 

- Inheritance - Parent-child relationship (IS-A Relationship)
