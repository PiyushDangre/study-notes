
## SOLID Principles

1. S - Single responsibility principle (SRP)
1. O - Open / Closed Principle - Classes/Interfaces should be open for extension and closed for modification
1. L - Liskov Substitution - derived or child classes must be able to replace their base or parent classes
1. I - Interface Segregation - Keep interfaces specific and well-defined / Prevent fat interfaces - create small interfaces.
1. D - Dependency Injection - High-level modules should not depend on low-level modules. Both should depend on abstractions. Big classes should always depend on interfaces.
